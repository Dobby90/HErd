# 사용 가이드

## 편집과 저장

**프로젝트**에서 로그인하고 프로젝트와 ERD를 만듭니다. 새 ERD를 만들 때 PostgreSQL 17을 선택합니다. 왼쪽 스키마 탐색에서 네임스페이스와 테이블을 추가하고 속성 패널에서 물리명·논리명·컬럼·키를 편집합니다. 같은 테이블을 여러 뷰에 배치할 수 있습니다. **이 뷰에서 숨기기**는 배치를 제거하고, **스키마에서 실제 삭제**는 관계와 뷰에 미치는 영향이 표시되는 확인 창을 엽니다.

FK를 추가하려면 컬럼의 오른쪽 핸들을 참조 대상 컬럼의 왼쪽 핸들로 드래그하거나 속성 패널의 **외래 키 추가**를 사용합니다. 복합 키는 부모 키의 각 컬럼에 다른 자식 컬럼을 대응시킵니다. **논리 관계**는 다이어그램에서 표기할 관계를 정의합니다. **스키마 및 뷰 검색**에서 이름을 검색하고 일치 항목을 선택하면 배치된 테이블로 이동합니다. **이름순 그리드 재배치**는 현재 뷰에 적용되며 실행 취소로 되돌릴 수 있습니다.

서버 문서는 편집 후 약 1초 뒤 자동 저장합니다. 저장 상태와 리비전은 편집기 상단에서 확인합니다. 충돌하면 **서버 최신본 확인**, **내 변경을 새 문서로 복제**, **변경 폐기 후 다시 열기** 중 하나를 선택합니다. 오프라인이나 로그인 만료 뒤에는 같은 계정으로 접속하고 **브라우저 복구본**에서 편집하던 상태를 엽니다.

## PostgreSQL DDL

- **DDL로 새 ERD 만들기**에서 SQL을 붙여 넣거나 UTF-8 `.sql` 파일을 올립니다. 기본 스키마를 정하고 **DDL 분석**을 실행합니다. 제외 항목이 있으면 누락되는 내용을 읽고 해당 분석의 확인란을 선택한 뒤 적용합니다. 문법 오류와 남은 모델의 미해결 참조는 입력을 수정해 다시 분석합니다.
- **DDL로 모델 교체**는 저장된 문서의 모델과 뷰를 바꿉니다. 기준 리비전과 제외 항목을 확인합니다. 교체 전 모델과 배치는 **버전 이력**에 보존됩니다.
- **DDL 내보내기**에서 전체, 현재 뷰 또는 선택한 테이블을 고릅니다. 부분 생성은 의존성을 확인한 뒤 SQL 생성으로 진행합니다. 성공 결과의 원본 리비전을 확인하고 복사하거나 UTF-8 `.sql`을 다운로드합니다. [지원 구문과 덤프 형식](sql-support/postgresql.md)

## 공유와 버전 이력

공유할 사람은 로그인한 프로젝트 목록에서 **내 공유 코드**를 확인합니다. owner는 프로젝트의 **멤버 관리**에서 코드를 입력해 사용자를 확인하고 역할을 선택합니다. Owner는 멤버를 관리하고, editor는 문서를 편집하고 복원할 수 있으며, viewer는 문서를 열고 SQL과 이미지로 출력할 수 있습니다.

**버전 이력**에서 저장 가능한 현재 리비전과 복원할 수 있는 스냅샷을 봅니다. **수동 스냅샷 저장**에는 설명을 붙일 수 있습니다. **과거 버전 열기**는 읽기 전용 도면을 보여줍니다. **이 버전으로 복원**을 확인하면 현재 상태를 보존하고 선택한 상태를 새 리비전에 저장합니다.

## 이미지 출력

**이미지 내보내기**에서 현재 뷰 전체 또는 선택한 테이블을 고릅니다. 물리명·논리명, 컬럼 표시, 그룹·메모, 배경, PNG 배율을 지정하고 **출력 미리보기**로 실제 범위를 확인한 뒤 PNG 또는 SVG 파일을 다운로드합니다. 범위 밖으로 이어지는 관계선은 미리보기에서 제외됩니다. PNG 크기 한도에 걸리면 배율을 낮추거나 작은 뷰를 선택해 다시 출력합니다.
